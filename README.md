# Ecosystem Population Dynamics Simulation

This project models a multi-species ecosystem using differential equations and numerical simulation in Python.

## Features
- Multi-species predator–prey modelling
- Numerical integration using SciPy
- Population time-series visualization
- Phase diagram analysis

## Technologies
Python
NumPy
SciPy
Matplotlib
Jupyter Notebook

## Model
The system extends Lotka–Volterra predator–prey equations to include 7 interacting species:
Plants, Herbivores, Omnivores, Carnivores, Scavengers, Saprophages, and Decomposers.

## Results
The simulation demonstrates:
- Predator–prey oscillations
- Long-term ecosystem dynamics
- Population stability behavior
